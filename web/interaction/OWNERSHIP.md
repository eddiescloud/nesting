# 交互模块归属

本目录由交互与整合 AI 维护。其他 AI 请在各自视觉/声音目录开发，通过 docs/INTEGRATION_CONTRACT.md 接入；需要改动本目录时先提出适配需求，不覆盖工作。

当前选择：原生 HTML/CSS/ES modules + Python 标准库本地服务。小型单屏交互不需要引入框架或构建链；后续视觉引擎保持独立。已有 Python 校验器通过本地接口复用，不再创建另一套语义/参数规则。

2026-09-11：用户决定恢复模型接入。本目录新增两个文件：
  - `voice.mjs`：麦克风采集与隐私生命周期（停止即归还音轨、退出释放回放地址）。录音只在内存与 Blob URL 中，不落盘、不上传。
  - `server.py` 新增 `POST /api/decode`：转发到 `10-语言解码/derive_bee.py` 的模型通道。**密钥只从环境变量 `NESTING_API_KEY` 读取，禁止写进本目录任何文件、日志或前端代码。**
蜂群视觉与音频仍由其他 AI 完成；本目录只负责界面、状态、拆解联动与生命周期对接。
