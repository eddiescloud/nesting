# 交互模块验收 · 2026-09-08

## 自动验证

- 17 项 Node 测试：阶段边界、重复开始、暂停不计时、完成/重播身份、退出清空、五轮模拟生命周期、消息来源与会话检查、迟到 ready、重复 ready、静音默认值、声音错误、退出后迟到解锁、时间回退。
- 10 项 Python HTTP 测试：静态页面、三份预设逐项复用原校验器、文字检查不回显不生成、非法输入、私有路径不发布、无 live 接口、错误来源与过大请求。
- 12 项原有 Python 校验测试通过。
- app.js 语法与启动脚本语法通过。无框架 build 或独立 lint 配置。

## 实际浏览器

使用 Codex 内置浏览器，而非截图替代 UI。已操作：选择第二个故事 → 开始 → 实时运行至 60 秒完成 → 再看一次 → 暂停 → 结束清空 → 填两句虚构测试文本 → 本机检查成功 → 重新开始 → 确认表单为空。

检查桌面 1280×720 和手机 390×844：无横向溢出；手机为上下布局；播放控制与分镜可访问。修正短屏首屏高度，1280×720 下页脚底部 702px，页面无需纵向滚动。浏览器未记录 JS error/warn；内置浏览器全屏进入和退出已验证。

## 视觉检查与范围

检查项目：文案来源标识、衬线标题/正文层级、米白与深绿对比、主按钮及故事选中态、左右分区与手机堆叠、短屏留白。实际截图已检查。交互层不生成或替代蜂群美术；沿用“模型先空置”的约束，没有调用图像模型，因此本轮不是生图概念复刻验收，也不声明与未存在的视觉设计稿一致。

可见的“分镜预览”“人工编排”等标识有意保留，避免被当作已接入 AI 的视觉作品。交互中的示例均为人工资料，不能用于模型能力评测。

## 未验证

真实视觉/声音模块尚未在本目录交付，桥接用隔离模拟测试，未完成与对方成品的端到端联调。五轮测试是状态机模拟，不是现场设备五轮验收。其他实际设备与浏览器的全屏兼容性、真实模型与赛事要求仍需后续验证。
